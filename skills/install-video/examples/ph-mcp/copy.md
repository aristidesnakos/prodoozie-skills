Title (55 chars):
Product Hunt MCP in Claude Code: install, sign in, ask

Description:
Product Hunt has an MCP server. Here it goes into Claude Code: one command, one sign-in, one question.

1. Copy the command from https://www.producthunt.com/mcp/install
   claude mcp add --transport http --scope user producthunt https://mcp.producthunt.com/mcp
2. Sign in with Product Hunt
   claude mcp login producthunt
   (or start Claude Code, run /mcp, choose producthunt, Authenticate)
3. Ask it something
   claude -p "List today's top 5 products on Product Hunt, one plain-text line each." --allowedTools mcp__producthunt__get_leaderboard
